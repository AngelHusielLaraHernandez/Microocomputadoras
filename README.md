# Microocomputadoras

## Estructura de carpetas

- %OUTDIR%/
  Directorio de salida de compilacion de LaTeX. Contiene los archivos auxiliares generados al compilar.

- img/
  Imagenes usadas en el documento principal.

- portada_img/
  Imagenes usadas en la portada.

- Previo1/
  Copia de trabajo anterior con su propio conjunto de archivos LaTeX, imagenes y carpeta %OUTDIR%.

## Archivos principales

- main.tex
  Documento principal de LaTeX.

- portada.tex
  Contenido de la portada.

- referencias.bib
  Base de datos bibliografica.
